# TeamHub — Application équipes

Application interne de gestion des équipes.

## V1
- Navigation par modules
- Tableau de bord
- Modèle de rôles : Administrateur / Manager / Salarié
- Fiches techniques
- To-do list avec assignation
- Besoins & interventions
- Rapports hebdomadaires
- Base de permissions prête à être remplacée par une authentification serveur

## Prochaine étape
1. Ajouter une vraie base de données.
2. Ajouter l'authentification sécurisée.
3. Gérer les établissements et utilisateurs.
4. Ajouter l'upload de fichiers.
5. Ajouter les emails automatiques.
6. Ajouter les formulaires et statuts métier.
7. Déployer l'application sur un hébergement web.

Le dépôt GitHub sert au versionnement du code. L'application et sa base de données devront être déployées sur une infrastructure adaptée.
